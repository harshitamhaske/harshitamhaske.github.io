Object Detection and Classification of Objects using Pointing Gestures

  • The proposed system combines MediaPipe Pose for human pose estimation and YOLOv4 for object detection, operating on live video feeds. The methodology involves detecting skeletal landmarks, calculating ground-projected interactions, and identifying objects intersecting with these interactions.
  • This research leverages the pointing gestures for human-robot interaction and add object detection and classification thereby helping robots understand the nature of objects and improve object manipulation.

    • Visualization and Output

  • Real-time visualization overlays skeletal landmarks, interaction lines, bounding boxes, and object labels on the video feed.
  • Color-coded markers (e.g., green for the shoulder, blue for the fingertip) and lines provide intuitive feedback on detected interactions.


    • Target Estimation

  • Pose Estimation Module: MediaPipe Pose is initialized to detect key skeletal landmarks from live video frames, enabling precise tracking of human body parts such as shoulders, fingertips, ankles etc.
  • Pose Estimation: Each video frame is processed to extract body landmarks. Coordinates of key points (e.g., shoulders, fingertips, and ankles) are mapped from normalized space to pixel space.
  • Ground Projection Calculation: A custom function computes the ground-point projection of a fingertip relative to a person's estimated height, enabling the system to extrapolate interactions extending toward the ground plane.
  • Object Detection: Frames are pre-processed into input blobs for YOLOv4. Detected objects are localized via bounding boxes, class labels, and confidence scores.

    • Object Detection and classification

  • Line-Based Interaction Detection: Lines connecting key body landmarks (e.g., shoulder to fingertip, fingertip to ground) are evaluated for intersection with detected object bounding boxes.
  • Bounding Box Intersection: A check determines if the ground-projected fingertip lies within the bounding box of an object, highlighting relevant interactions with visual markers.

    • Results

    1) Scenario 1: Controlled Environment:

  • Setup: A single user in a well-lit room with objects placed on the floor.
  • Outcome: The system consistently detected the user’s pose, objects, and fingertip-object interactions.
  • Observations: No significant latency; high accuracy in both pose tracking and interaction detection.

    • 2) Scenario 2: Semi-Dynamic Environment:

  • a) Setup: A user moving moderately while objects were shifted within the frame.
  • b) Outcome: The system maintained reliable tracking and interaction detection, though with minor lag during fast object motion.
  • c) Observations: YOLO struggled with detecting very small or fast-moving objects, affecting interaction analysis accuracy.

    Conditions for testing

    • Low lighting led to reduced accuracy in both pose estimation and object detection. • Adding pre-processing steps like brightness normalization is suggested for future iterations.
